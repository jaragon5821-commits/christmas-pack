# Chop's Christmas Special (pack)

Private friends-only NeoForge 1.21.1 modpack (NeoForge 21.1.265), delivered with packwiz.
This branch (test) is the TEST feed. main is for the finished release.
**If you see "Incompatible client! Please use NeoForge 21.1.265":** in Prism, right-click the instance, Edit, Version, select NeoForge and click Change version, pick **21.1.265**, then launch again. The server only accepts that exact NeoForge version.
