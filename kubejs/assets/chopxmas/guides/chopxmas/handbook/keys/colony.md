# Colony Building

Keys for placing and moving building previews, and for your colony tools.

**Your keys right now.** Keys marked **Unassigned** start with no key: click the link to open Keybind Atlas, then pick the key there (Edit, then the Unassigned list).

<OptionalSection modId="structurize">

### Structurize (building previews)

Use these while a building preview is showing.

* Place the building: **<KeyBind id="key.structurize.place" />**
* Rotate clockwise: **<KeyBind id="key.structurize.rotate_cw" />**
* Rotate anticlockwise: **<KeyBind id="key.structurize.rotate_ccw" />**
* Mirror: **<KeyBind id="key.structurize.mirror" />** · <CommandLink command="/chopkeys" close={true} title="Opens Keybind Atlas">Unassigned: click to assign</CommandLink>
* Move forward: **<KeyBind id="key.structurize.move_forward" />**
* Move back: **<KeyBind id="key.structurize.move_back" />**
* Move left: **<KeyBind id="key.structurize.move_left" />**
* Move right: **<KeyBind id="key.structurize.move_right" />**
* Move up: **<KeyBind id="key.structurize.move_up" />**
* Move down: **<KeyBind id="key.structurize.move_down" />**
* Teleport with the scan tool: **<KeyBind id="key.structurize.teleport" />**

</OptionalSection>

## Set your own keys

<CommandLink command="/chopkeys structurize,minecolonies,minecolonies_tweaks" close={true} title="Opens Keybind Atlas showing only these keys">Show these keys in Keybind Atlas</CommandLink>

Atlas opens showing just these mods' keys that already have a key. Keys marked *Not bound* above are in Atlas under **Edit** (pencil) then **Unassigned**: type the mod name in its search, click one, press the key you want, then **Apply**.
You can also open Keybind Atlas any time with **<KeyBind id="key.keybindatlas.open_keyboard" />**.
