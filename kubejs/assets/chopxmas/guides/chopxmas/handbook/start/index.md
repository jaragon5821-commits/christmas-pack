# Getting Started

You start with nothing but this book. Everything else you find, craft or earn.

1. Punch a tree, make tools, find shelter before the first night. It's cold out there.
2. Open the quest book with **<KeyBind id="key.ftbquests.quests" />**. It points you at your next step.
3. When you're ready, start a colony (see **Your Colony**).
